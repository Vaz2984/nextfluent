B1 · Lição 3: Condicionais (First and Second Conditional)

Objetivos da lição

  • Usar a zero conditional para fatos gerais
  • Usar a first conditional para situações reais/prováveis
  • Usar a second conditional para situações hipotéticas

Explicação

Frases condicionais têm duas partes: a condição (if clause) e o resultado (main clause).

1. Zero Conditional: fatos e verdades gerais

Estrutura: If + presente simples, presente simples

If you heat ice, it melts. → Se você aquece o gelo, ele derrete. (sempre verdadeiro) If it rains, the ground gets wet.

2. First Conditional: situações reais/prováveis no futuro

Estrutura: If + presente simples, will + verbo

Usada para condições possíveis e realistas:

If it rains tomorrow, I will stay home. → Se chover amanhã, eu vou ficar em casa. (é possível que chova) If you study hard, you will pass the exam. She will be upset if you don't call her.

Nunca use "will" depois do "if": If it will rain (errado) → If it rains (correto)

3. Second Conditional: situações hipotéticas/improváveis

Estrutura: If + passado simples, would + verbo

Usada para situações imaginárias, hipotéticas ou pouco prováveis no presente/futuro:

If I won the lottery, I would travel around the world. → Se eu ganhasse na loteria, eu viajaria pelo mundo. (hipotético, imaginário) If I were you, I would apologize. → Se eu fosse você, eu pediria desculpas. (conselho hipotético, muito comum!) What would you do if you had a million dollars?

No second conditional, usamos "were" para todos os pronomes com o verbo to be (inclusive I/he/she), especialmente na expressão "If I were you": If I were rich... (não "If I was rich", embora "was" também seja aceito informalmente)

4. Comparando as três condicionais

Tipo Estrutura Uso Exemplo
Zero if + presente, presente fato geral/científico If you mix red and blue, you get purple.
First if + presente, will real, provável If I have time, I will call you.
Second if + passado, would hipotético, improvável If I had time, I would call you.

Repare a diferença de significado: "If I have time, I will call you" (é bem provável que eu tenha tempo) x "If I had time, I would call you" (não tenho tempo agora, é hipotético).

5. Unless (= if not)

Unless you hurry, you will miss the bus. = If you don't hurry, you will miss the bus. → A menos que você se apresse, você vai perder o ônibus.

Vocabulário: Verbos úteis em condicionais

win the lottery (ganhar na loteria), pass/fail an exam (passar/reprovar em uma prova), apologize (pedir desculpas), afford (ter condições financeiras), succeed (ter sucesso)

Diálogo modelo

A: What would you do if you won the lottery? B: If I won a lot of money, I would quit my job and travel. What about you? A: I would buy a house. But if I don't win, I'll just keep working hard! B: If I were you, I would also save some money, just in case!

Exercícios

1) Complete com zero, first ou second conditional (conjugue os verbos):

a) If water (reach) 100°C, it (boil). (zero) b) If I (have) enough money, I (buy) a new car. (hipotético) c) If you (not/study), you (fail) the exam. (real/provável) d) If I (be) you, I (talk) to her.

3) Traduza:

a) Se eu fosse rico, eu ajudaria mais pessoas. → b) Se você estudar, você vai passar. → c) Se você aquecer o gelo, ele derrete. →

Gabarito

1) a) reaches / boils; b) had / would buy; c) don't study / will fail; d) were / would talk

2) Unless you hurry, you will be late.

3) a) If I were rich, I would help more people. b) If you study, you will pass. c) If you heat ice, it melts.
