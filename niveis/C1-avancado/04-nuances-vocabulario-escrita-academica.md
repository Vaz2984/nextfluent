# C1 · Lição 4: Nuances de Vocabulário e Escrita Acadêmica

## Objetivos da lição

- Entender diferenças sutis entre sinônimos (nuances de significado e conotação)
- Escrever com registro acadêmico/formal
- Evitar erros comuns de falantes avançados

## Explicação

### 1. Nuances entre sinônimos comuns

Em C1, o desafio não é mais "saber a palavra", mas **escolher a palavra certa para o contexto e o tom certo**.

| Palavras similares | Diferença |
|---|---|
| **big / large / huge / enormous / massive** | big = neutro; large = mais formal; huge/enormous/massive = ênfase em tamanho extremo |
| **happy / glad / delighted / thrilled** | happy = neutro; glad = mais suave/educado; delighted = formal, forte; thrilled = muito empolgado, informal |
| **say / state / claim / assert** | say = neutro; state = formal, factual; claim = alegar (dúvida implícita); assert = afirmar com convicção |
| **look at / observe / examine / scrutinize** | look at = neutro; observe = mais atento; examine = detalhado; scrutinize = minucioso, crítico |
| **problem / issue / dilemma / predicament** | problem = neutro; issue = mais formal/tema; dilemma = escolha difícil; predicament = situação difícil sem saída fácil |
| **want / wish / desire / long for** | want = neutro; wish = mais educado/hipotético; desire = formal, forte; long for = anseio, literário |

> Usar "claim" em vez de "say" muda o tom: "He **said** he was innocent" (neutro) x "He **claimed** he was innocent" (sugere dúvida sobre a veracidade).

### 2. Conotação positiva, negativa e neutra

Palavras com significado parecido podem ter **carga emocional diferente**:

| Neutro | Positivo | Negativo |
|---|---|---|
| thin | slim/slender | skinny |
| curious | inquisitive | nosy |
| confident | self-assured | arrogant |
| careful | cautious | paranoid |
| frugal | economical | stingy/cheap |

> She's very **curious** about everything. (neutro) → She's very **inquisitive**. (positivo, elogio) → She's so **nosy**! (negativo, crítica)

### 3. Registro formal x informal na escrita

| Informal | Formal (acadêmico) |
|---|---|
| a lot of | numerous / a significant number of |
| get | obtain / receive |
| find out | determine / discover |
| big | substantial / considerable |
| show | demonstrate / indicate |
| but | however / nevertheless |
| also | furthermore / moreover |
| kids | children |
| a bit | somewhat / slightly |
| really | significantly / considerably |

> Informal: *We got a lot of good results, but there's still a lot to do.*
> Formal: *We **obtained** **numerous** favorable results; **however**, **considerable** work **remains**.*

### 4. Erros comuns em nível avançado (falsos avanços)

- **Overusar "very"** em vez de adjetivos mais precisos: em vez de "very big", use "enormous"; em vez de "very tired", use "exhausted".
- **Confundir "affect" (verbo) e "effect" (substantivo)**: *The policy will **affect** many people.* / *The **effect** of the policy is unclear.*
- **Usar "actually" traduzindo "atualmente"**, errado! "Actually" significa "na verdade". "Atualmente" = **currently/nowadays**.
- **Confundir "economic" (relativo à economia) e "economical" (que economiza)**: *economic growth* x *an economical car*.

## Vocabulário: Adjetivos precisos (para substituir "very + adjetivo")

very big → enormous/huge | very small → tiny | very tired → exhausted | very scared → terrified | very happy → thrilled/ecstatic | very good → excellent/outstanding | very bad → awful/terrible | very hungry → starving

## Prática

> **Currently**, the company faces a **considerable** challenge: **numerous** clients have **claimed** that the new software **negatively affects** performance. The team must **determine** the root cause. **Furthermore**, the **effect** on customer trust could be **substantial** if the issue is not resolved soon.

## Exercícios

**1)** Substitua a palavra sublinhada por uma opção mais formal:

a) We got a lot of feedback. → We ▁▁▁ ▁▁▁ feedback.
b) The results show that... → The results ▁▁▁ that...
c) But we still need more data. → ▁▁▁, we still need more data.

**2)** Escolha a palavra com a conotação correta:

a) She asks a lot of questions about everyone's life. She's very ▁▁▁ (nosy/inquisitive), negativo.
b) He always thinks before acting. He's ▁▁▁ (cautious/paranoid), positivo.

**3)** Corrija o erro:

a) "Actually, I work as a teacher." *(significando "atualmente")* → ▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁
b) "The affect of the new law is unclear." → ▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁

**4)** Traduza usando um adjetivo mais preciso do que "very + adjetivo":

a) Ela estava muito cansada. → ▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁
b) O prédio é muito grande. → ▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁

## Gabarito

**1)** a) obtained / numerous; b) demonstrate/indicate; c) However

**2)** a) nosy, b) cautious

**3)** a) Currently, I work as a teacher., b) The **effect** of the new law is unclear.

**4)** a) She was exhausted., b) The building is enormous/huge.
