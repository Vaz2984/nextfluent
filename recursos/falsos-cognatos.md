# Falsos Cognatos (False Friends)

Falsos cognatos são palavras parecidas em português e inglês, mas com **significados diferentes**. Eles são uma das maiores armadilhas para brasileiros aprendendo inglês, cuidado com elas!

| Palavra em inglês | Parece com... | Mas significa | A palavra certa para o "falso amigo" é |
|---|---|---|---|
| actually | atualmente | na verdade | nowadays / currently |
| pretend | pretender | fingir | intend |
| push | puxar | empurrar | pull |
| pull | pular | puxar | jump |
| parents | parentes | pais (mãe e pai) | relatives |
| exit | êxito | saída | success |
| costume | costume (hábito) | fantasia (roupa) | habit / custom |
| library | livraria | biblioteca | bookstore |
| fabric | fábrica | tecido | factory |
| lecture | leitura | palestra/aula | reading |
| notice | notícia | perceber/aviso | news |
| assist | assistir (TV) | ajudar | watch |
| pasta | pasta (arquivo) | massa (comida) | folder |
| college | colégio | faculdade | high school |
| policy | polícia | política (regras) | police |
| resume | resumo | currículo (ou: retomar) | summary |
| sensible | sensível | sensato/razoável | sensitive |
| eventually | eventualmente | finalmente/no fim | occasionally / sometimes |
| realize | realizar (fazer) | perceber/se dar conta | to carry out / to accomplish |
| intend | entender | pretender/ter intenção | understand |
| appointment | apontamento | compromisso/consulta marcada | note |
| argument | argumento | discussão/briga (também "argumento") | *(atenção: também pode ser briga)* |
| casualty | casualidade | vítima (ferido/morto) | coincidence |
| deception | decepção | engano/fraude | disappointment |
| fastidious | fastidioso (chato) | exigente/minucioso | boring / tedious |
| genial | genial | gentil/simpático | brilliant |
| ordinary | ordinário | comum/normal | vulgar / rude |
| pretend | pretender | fingir | intend / plan |
| retire | retirar | aposentar-se | withdraw / remove |
| sympathetic | simpático | compreensivo/solidário | nice / friendly |
| vegetable | vegetal | legume/verdura | *(uso correto, mas "vegetal" em pt-br é mais amplo)* |
| terrific | terrível | ótimo/incrível | terrible / awful |
| lunch | lanche | almoço | snack |
| data | data (calendário) | dados (informação) | date |
| idiom | idioma | expressão idiomática | language |

## Dica de estudo

Sempre que encontrar uma palavra em inglês parecida com o português, **desconfie antes de assumir o significado**. Consulte um dicionário confiável (ex: Cambridge Dictionary, Oxford Learner's Dictionary) até ter certeza, e depois de descobrir uma pegadinha, crie uma frase para gravar o significado correto.
