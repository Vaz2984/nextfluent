Trabalho · Lição 9: Vocabulário por Área Profissional

Objetivos da lição

  • Conhecer o vocabulário essencial de áreas comuns do mercado de trabalho
  • Ter uma referência rápida para consultar conforme sua profissão

Vocabulário por área

1. Tecnologia / TI (Technology / IT)

Inglês Português
software development desenvolvimento de software
bug / to debug erro / depurar (corrigir erro)
deploy / deployment implantação (colocar em produção)
backend / frontend back-end / front-end
database banco de dados
API interface de programação (API)
version control controle de versão
sprint sprint (ciclo de desenvolvimento ágil)
stakeholder requirements requisitos das partes interessadas
scalability escalabilidade
downtime tempo de inatividade
code review revisão de código

2. Finanças (Finance)

Inglês Português
balance sheet balanço patrimonial
cash flow fluxo de caixa
assets / liabilities ativos / passivos
equity patrimônio líquido
audit auditoria
fiscal year ano fiscal
interest rate taxa de juros
portfolio carteira (de investimentos)
forecast previsão/projeção
accounts payable/receivable contas a pagar/receber

3. Marketing

Inglês Português
target audience público-alvo
brand awareness reconhecimento de marca
lead generation geração de leads
conversion rate taxa de conversão
campaign campanha
content strategy estratégia de conteúdo
engagement engajamento
SEO (search engine optimization) otimização para mecanismos de busca
A/B testing teste A/B
customer journey jornada do cliente

4. Vendas (Sales)

Inglês Português
lead possível cliente/lead
pipeline funil/pipeline de vendas
quota meta (de vendas)
pitch discurso de vendas
cold call ligação fria (sem contato prévio)
closing a deal fechar um negócio
upsell / cross-sell venda adicional / venda cruzada
churn rate taxa de cancelamento/perda de clientes
negotiation negociação
commission comissão

5. Recursos Humanos (Human Resources: HR)

Inglês Português
recruitment recrutamento
onboarding integração de novo funcionário
performance review avaliação de desempenho
turnover rate taxa de rotatividade
employee benefits benefícios do funcionário
compliance conformidade (com normas/leis)
workplace culture cultura organizacional
diversity and inclusion diversidade e inclusão
layoffs demissões (em massa)
exit interview entrevista de desligamento

6. Atendimento ao Cliente (Customer Service)

Inglês Português
customer satisfaction satisfação do cliente
ticket chamado/solicitação
escalation escalonamento (de um problema)
refund reembolso
SLA (service level agreement) acordo de nível de serviço
feedback retorno/opinião
complaint reclamação
resolution resolução
follow-up acompanhamento posterior

Frases úteis por área

TI: "We found a critical bug in production and need to deploy a hotfix." (Encontramos um erro crítico em produção e precisamos implantar uma correção urgente.) Finanças: "Our cash flow improved significantly this quarter." (Nosso fluxo de caixa melhorou significativamente este trimestre.) Marketing: "The campaign increased our conversion rate by 12%." (A campanha aumentou nossa taxa de conversão em 12%.) Vendas: "I closed the deal after three follow-up calls." (Fechei o negócio depois de três ligações de acompanhamento.) RH: "We're focusing on improving our onboarding process." (Estamos focando em melhorar nosso processo de integração.) Atendimento: "This ticket needs to be escalated to the technical team." (Este chamado precisa ser escalado para a equipe técnica.)

Exercícios

1) Relacione o termo à área correta:

a) churn rate, ( ) TI b) deploy, ( ) Vendas c) balance sheet, ( ) Finanças d) onboarding (funcionário), ( ) RH

2) Complete com a palavra correta da sua área de interesse (escolha uma): "Our team improved the rate by focusing on customer experience." (conversion / churn / turnover)

3) Escreva 3 frases sobre seu trabalho atual (ou desejado) usando vocabulário desta lição.

Gabarito

1) a) Vendas; b) TI; c) Finanças; d) RH

2) Resposta livre, todas as opções são gramaticalmente corretas dependendo do contexto.

3) Resposta livre.
